# DATA Folder

* In this folder, you should place:
    - `makaao_core.xlsx`
    - `en_product4.xml`, obtained from Orphanet (https://www.orphadata.com/data/xml/en_product4.xml)
    - `MRCONSO.RRF`, obtained from the UMLS (https://www.nlm.nih.gov/research/umls/licensedcontent/umlsknowledgesources.html)

* As our scripts run, they will create subfolders `processed_tables` and `enrichment_tables` with CSV files in them.
